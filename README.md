# PreDash Classroom · 수강생 투자 대시보드

선생님의 PreDash와 분리한 수업용 코드입니다. 개인 계좌를 조회하고 시장·기업·수급·차트를 보면서 나만의 투자 화면을 실습합니다. 실제 주문 전송 기능은 없습니다.

## 수강생 시작 순서

1. 이 저장소의 Fork 버튼 → 본인 계정에 복사합니다.
2. Streamlit Community Cloud에서 본인 Fork의 main / app.py를 배포합니다.
3. 앱 Settings → Secrets에 APP_PASSWORD를 설정합니다. 기업 분석용 DART·공공데이터 키는 .streamlit.example.toml의 빈 항목을 본인 키로 설정합니다.
4. 앱 로그인 → 연결 설정 → 모의투자 선택 → 본인 App Key·App Secret·계좌번호 입력 → 연결 확인.
5. 관심종목·투자 근거·대시보드를 자신의 기획에 맞춰 수정합니다.

증권사 키는 Secrets나 GitHub에 저장하지 않습니다. 접속 세션에서만 사용하며 연결 해제·로그아웃 시 키와 접속 중 실습 자료를 제거합니다. 필요한 실습 기록은 먼저 백업하세요. 서버가 키를 처리하므로 각자 관리하는 앱에서 사용하세요.

## 업데이트

### UI 3.0 · 시장 상태와 전환 팝업

대시보드·관심종목·투자 근거·내 계좌 화면에 시장/집중도/자료 상태, 월말 점검, 알림 이력을 추가했습니다. 네이비·청록 카드 화면은 모바일에서 세로로 정렬됩니다. Prime은 기획 안내만 표시하며 PG·결제·유료 권한 제한은 없습니다.

- 4단계: VIX 15 미만 안정, 15 이상 주의, 20 이상 경계, 30 이상 위험. 국내 지수는 10·20일선 모두 위 안정, 사이·일치 주의, 모두 아래 경계. 입력 중 가장 높은 단계를 적용합니다.
- 팝업: 최초 경계·위험 또는 단계 악화에 표시합니다. 주의는 배너만 표시합니다. 개선은 완전한 자료가 서로 다른 두 국내 관측일에 확인돼야 확정합니다. 두 지수 모두 상승·VIX 20 미만 조건도 충족하면 분할 투자 검토 팝업을 표시합니다. 최초 좋은 상태는 전환으로 주장하지 않습니다.
- 불완전한 자료: 낮은 위험 입력만 있으면 판정 보류. 유효한 경계·위험 근거가 있으면 최소 위험 단계를 표시하되 개선을 확정하지 않습니다. 장중 당일 국내 일봉은 종가 확정을 주장하지 않도록 16시(KST) 전에는 판정에서 제외합니다.
- 자료: 미래·비정상 값이나 5일을 초과한 종가는 배제합니다. 국내 지수 조회 후 24시간이 지나면 재검증합니다. 누락/오래된 자료는 회복으로 간주하지 않습니다. 이는 영업일 캘린더 대신 사용하는 보수적 달력일 기준입니다.
- 집중도: 최신 15분 이내 국내주식 평가액을 종목코드별 합산해 계산합니다. 기본 40% 초과에 배지를 표시하며 사용자가 기준을 변경할 수 있습니다. 현금·해외자산은 제외합니다.
- 팝업: 최초 경계/위험 진입·단계 악화·확인된 긍정 전환에 표시합니다. 같은 단계의 당일 반복 팝업은 억제하고, X/ESC/확인으로 닫아도 다음 새로고침에 같은 알림을 다시 띄우지 않습니다. 최근 이력에서 다시 열 수 있습니다. 팝업 끄기는 이후 전환에 적용됩니다.
- 갱신: 활성 브라우저 세션에서 60초마다 점검합니다. VIX 캐시는 30분, 국내 지수 재조회 간격은 5분입니다. 장중 실시간 신호나 브라우저 종료 후 푸시 알림은 아닙니다. 상태 기억/알림 이력은 접속 세션에만 보관되어 서버 재시작·로그아웃 뒤에는 초기화됩니다.
- 팝업의 비중 점검/투자 근거 버튼은 해당 화면으로 이동합니다. 증권사 주문 API는 추가하지 않았습니다. 개인별 적합성·수익 보장이나 자동 주문이 아닌 시장 공통 규칙에 따른 검토 안내입니다.

확인: `python -m unittest discover -p "tests_*.py" -v`. 합성 자료로 위험/주의/긍정/누락·노후 데이터, 두 관측일 확인, 반복 억제, 집중도, 팝업 닫기와 화면 이동을 검증합니다.

팝업 UI 미리보기: `streamlit run preview_alerts.py`. 별도 합성 자료 화면이며 실제 앱의 시장 판정이나 계좌에 쓰이지 않습니다.

선생님 배포본 업데이트는 본인 Fork의 Sync fork로 반영합니다. 본인 변경과 충돌하면 덮어쓰기 전에 비교하세요. 이 저장소는 원본 PreDash의 046f13530430a1e2c9415775bf51b7fdfdc49d97을 기준으로 새 이력으로 배포합니다.
